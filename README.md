# Create Feature Map

このスキルは、Lauren Tan の P-stack にある `create-verification-skill` から、フィーチャーマップの作成部分だけを切り出し、日本語で再構成したものです。[元のスキルの該当箇所](https://github.com/cursor/plugins/blob/main/pstack/skills/create-verification-skill/SKILL.md#3-seed-the-feature-map)

## 使い方

1. このスキルの3ファイルを、使いたいリポジトリの `.agents/skills/create-feature-map/` に置きます。
2. Codexでそのリポジトリを開き、たとえば `$create-feature-map 検索機能のフィーチャーマップを作って` と依頼します。

[Codexのスキルガイド](https://learn.chatgpt.com/docs/customization/overview#skills)
